# Проверка перед публикацией

- [ ] Сравнить с исходной версией на 1440, 1280, 1024, 768, 390, 320 px.
- [ ] Проверить экран высотой 600 px, поворот устройства и масштаб 200%.
- [ ] Проверить меню мышью, касанием, Tab, Enter и Escape.
- [ ] Проверить все якорные ссылки и отсутствие переходов в неправильные разделы.
- [ ] Проверить цвета и WCAG AA инструментом Lighthouse / axe / Contrast Checker.
- [ ] Проверить изображения, alt, веса и размеры; оценить WebP/AVIF отдельно.
- [ ] Проверить даты новостей и факты по официальным материалам.
- [ ] Проверить мобильный Safari, Chrome и Firefox.
- [ ] Запустить Lighthouse для Performance, Accessibility, Best Practices и SEO.
- [ ] Убедиться, что исходный GitHub и опубликованный Cloudflare не изменены до согласования.
