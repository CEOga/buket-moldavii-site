# Buket Moldavii

Responsive website for Buket Moldavii, built from the supplied desktop, tablet, and mobile Figma layouts.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Cloudflare Pages

This is a static site. Use the repository root as the project root, leave the build command empty, and set the build output directory to `.`. Deploy the `main` branch.
