# Buket Moldavii — Foundation v2 / дизайн-система

## Подход
Сохранена существующая тёплая коричнево-кремовая визуальная концепция и стек HTML/CSS/JS. Это не полный ребрендинг. Новые страницы должны использовать общие токены и существующие паттерны.

## Цвета (из исходного CSS)
- `--ink: #211b16` — основной текст.
- `--brown: #7b4b19` — основные акценты и контуры.
- `--brown-dark: #4d2c17` — насыщенный акцент.
- `--gold: #bd925b` — декоративный акцент; **не** использовать как единственный цвет мелкого текста на светлом фоне без проверки контраста.
- `--line: #dfc9ad` — границы.
- `--cream: #fbf8f3` — альтернативная поверхность.
- `--paper: #fffefa` — основная поверхность.
- `--text-secondary: #544b42` — дополнительный текст.
- `--focus: #f0c27b` — фокус на тёмных поверхностях; на светлых поверхностях может потребоваться более тёмный вариант.

## Типографика
- Заголовки: Playfair Display; интерфейс и основной текст: Inter.
- Основной текст: 16 px, line-height 1.6.
- Второстепенный текст: не менее 14 px, кроме декоративных подпунктов с обоснованным исключением.
- H2: `clamp(34px, 4.5vw, 50px)`.
- Hero H1: существующий `clamp(54px, 6vw, 80px)`; мобильная адаптация через media query.
- Не использовать произвольные размеры без привязки к общей шкале.

## Layout
- `--shell: 1264px`; горизонтальные поля: 32 px на desktop, 20 px на mobile, 16 px на узких экранах.
- Шкала отступов: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px.
- Карточки: радиус 22 px desktop, 18 px mobile; кнопки — pill.
- Для новых компонентов обязательно: default / hover / focus-visible / disabled (если применимо).

## Ограничения
- Нет корзины, оплаты, фальшивых ссылок и вымышленных фактов.
- Данные о дивинах, событиях и дегустациях требуют редакторской проверки.
- Цветовые сочетания и адаптивность требуют дополнительной ручной проверки в браузере.
